# 项目运行流程说明

## 主流程

### 1. 启动后端
后端负责统一提供分析、案件与举报接口。

### 2. 触发演示分析
通过网页端按钮或后端接口触发一次完整分析任务。

### 3. 后端处理链
后端会依次执行：

- 读取演示视频
- 抽样关键帧
- 调用智谱视觉识别是否占用应急车道
- 读取车牌号
- 通过时序规则融合为事件
- 按车牌归档为案件
- 生成证据图
- 生成 15 秒证据片段
- 生成正式举报文书

### 4. 网页端展示
网页端展示：

- 总览指标
- 事件列表
- 案件库
- 证据链
- 文书
- 模拟举报状态

### 5. Android 端展示
Android 端连接同一套后端接口，展示：

- 案件列表
- 案件详情
- 证据片段播放
- 正式举报文书
- 案件模拟举报入口

## 典型使用方式

- 后端作为数据与业务中枢；
- 网页端作为全局总览与操作入口；
- Android 端作为移动查看与处理入口。

这种方式保证三部分围绕同一套数据模型运行，而不是各自维护独立业务链。
