# 当前项目实现范围

## 1. 后端模块
- analysis run 历史管理
- source video 枚举与选择
- 演示视频抽样分析
- 智谱视觉识别接入
- 时序融合规则
- 事件到案件的归档逻辑
- 案件人工复核字段维护
- 15 秒证据片段生成
- 正式举报文书生成
- run / event / case / report API
- 事件/案件过滤查询

## 2. 网页端模块
- overview 与 latest run 展示
- run 历史面板
- source selector
- 事件列表筛选
- 案件列表筛选
- 案件详情与证据链
- 案件复核编辑表单
- 举报状态联动展示

## 3. Android 端模块
- 后端 API 对接
- run 摘要展示
- 案件状态筛选
- 移动端案件列表与详情界面
- 片段播放、证据查看
- 复核字段展示与更新
- 举报状态同步展示
