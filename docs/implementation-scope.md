# 当前项目实现范围

## 1. 后端模块
- analysis run 历史管理
- source video 枚举与选择
- 演示视频抽样分析
- 后端视觉识别服务接入（默认 mock 演示识别，可选接第三方视觉服务）
- 时序融合规则
- 事件到案件的归档逻辑
- 案件人工复核字段维护
- 15 秒证据片段生成
- 正式举报文书生成
- run / event / case / report API
- 事件/案件过滤查询

## 2. 网页端模块
- overview 与 latest run 展示
- 与 Android 协同端对齐的浅紫主题总览布局
- run 历史面板
- source selector
- 事件列表筛选
- 案件列表筛选
- 案件详情与证据链
- 案件复核编辑表单
- 举报状态联动展示

## 3. Android 端模块
- 后端 API 对接
- run 摘要展示
- 案件状态筛选
- 移动端案件列表与详情界面
- 片段播放、证据查看
- 复核字段展示与更新
- 举报状态同步展示
- 连接诊断卡与运行期 API 地址切换
- 分层结构：model / network / viewmodel / ui
- 端侧本地检测模式入口
- CameraX 相机检测
- JNI + ncnn 本地检测链
- Room 本地待处理记录与案例库
- HyperLPR3 本地车牌识别
- 本地视频裁剪与本地报告生成

## 4. 这次明确不做的内容
- 不扩到账号系统 / 在线同步 / 真实平台接入
- 不优先做 README 卡片化介绍或答辩文案型页面
- 不要求本轮把 APK 安装到本地设备重新测试
- 不把端侧本地链直接做成自动双向同步系统
